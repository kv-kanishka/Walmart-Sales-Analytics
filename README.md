# Walmart Sales Data Analysis | End-to-End Python + SQL Project

## Project Overview

This project demonstrates an end-to-end data analytics workflow using Python and SQL to analyze Walmart sales data. The objective is to transform raw sales data into meaningful business insights through data cleaning, feature engineering, SQL analysis, and business problem solving.

The project covers the complete analytics lifecycle, starting from data extraction to querying structured databases for decision-making.

---

## Business Problem

Retail businesses generate large volumes of transactional data every day. Understanding this data helps identify customer purchasing patterns, sales performance, payment preferences, and product profitability.

This project analyzes Walmart sales transactions to answer real-world business questions that support data-driven decision-making.

## Workflow

### 1. Data Collection

- Downloaded Walmart sales dataset using the Kaggle API.

### 2. Data Cleaning & Processing

- Imported dataset into Python
- Removed inconsistencies
- Handled missing values
- Performed feature engineering
- Created additional analytical columns

### 3. Database Integration

Loaded the cleaned dataset into:

- MySQL
- PostgreSQL

using SQLAlchemy.

### 4. SQL Analysis

Performed business analysis using SQL to answer practical business questions such as:

- Payment method analysis
- Revenue analysis
- Category-wise sales
- Profit analysis
- Branch performance
- Customer buying behaviour
- Sales trends
- Peak shopping hours

### 5. Business Insights

Generated meaningful insights that can help businesses understand:

- Customer payment preferences
- Best-performing product categories
- Sales distribution
- Revenue trends
- Customer purchasing patterns
- Branch performance

---

## Business Problems Solved

The project answers several business questions, including:

- Analyze payment methods and sales performance.
- Identify the highest-rated product category in each branch.
- Determine the busiest day for each branch.
- Calculate total quantity sold by payment method.
- Analyze category ratings across different cities.
- Calculate total profit by product category.
- Identify the most common payment method in each branch.
- Analyze sales across different shifts.
- Identify branches with the highest revenue decline year-over-year.
